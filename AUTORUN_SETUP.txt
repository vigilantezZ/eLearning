================================================================
  BMPTryout - AUTO RUN SETUP (Windows Task Scheduler)
================================================================

[ METODE 1: PALING MUDAH (1-KLIK) ]

  Cukup copy file BMPTryout.exe dan install_autorun.bat ke folder tujuan:
    C:\PROJECT\Production\eLearning\

  Lalu klik 2x file:
    C:\PROJECT\Production\eLearning\install_autorun.bat

  Script ini otomatis mendeteksi lokasi folder tersebut, meminta akses Administrator (UAC), 
  dan mendaftarkan Task Scheduler dengan Working Directory yang tepat ke C:\PROJECT\Production\eLearning.


[ METODE 2: MANUAL VIA POWERSHELL ADMINISTRATOR ]

  Buka PowerShell (Run as Administrator), lalu copy-paste perintah berikut:

  $action = New-ScheduledTaskAction -Execute "C:\PROJECT\Production\eLearning\BMPTryout.exe" -WorkingDirectory "C:\PROJECT\Production\eLearning"
  $triggerBoot = New-ScheduledTaskTrigger -AtStartup
  $triggerBoot.Delay = 'PT10S'
  $triggerLogon = New-ScheduledTaskTrigger -AtLogOn
  $principal = New-ScheduledTaskPrincipal -UserId "NT AUTHORITY\SYSTEM" -LogonType ServiceAccount -RunLevel Highest
  $settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1) -ExecutionTimeLimit (New-TimeSpan -Days 0)
  Register-ScheduledTask -TaskName "BMPTryout" -Action $action -Trigger @($triggerBoot, $triggerLogon) -Principal $principal -Settings $settings -Description "BMP CBT Tryout Standalone WSGI Server" -Force


[ CEK STATUS / TESTING ]

  1. Jalankan manual sekarang:
     Start-ScheduledTask -TaskName "BMPTryout"

  2. Cek status apakah sedang Running:
     Get-ScheduledTask -TaskName "BMPTryout"

  3. Akses Web di Browser:
     http://localhost:5000


[ UNINSTALL / STOP AUTO-RUN ]

  Cukup klik 2x file:
    d:\Project\eLearning\uninstall_autorun.bat

  Atau via PowerShell Administrator:
    Unregister-ScheduledTask -TaskName "BMPTryout" -Confirm:$false
